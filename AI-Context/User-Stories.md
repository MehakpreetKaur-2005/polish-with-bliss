**Last Updated:** August 2026

---

# 1. Purpose

This document defines the functional user stories for the Polish with Bliss website.

The user stories describe the application's functionality from the user's perspective and represent the business requirements that guide frontend development.

Each user story follows the standard Agile format:

> As a <user>, I want <goal>, so that <benefit>.

---

# 2. User Stories

| ID | User Story | Priority |
|----|------------|----------|
| US-001 | As a visitor, I want to immediately understand what Polish with Bliss offers, so that I know whether the services meet my needs. | High |
| US-002 | As a visitor, I want to easily navigate between different sections of the website, so that I can quickly find the information I need. | High |
| US-003 | As a potential client, I want to explore the available beauty services, so that I can decide which treatment interests me. | High |
| US-004 | As a potential client, I want to view transparent pricing for all services, so that I know the expected cost before booking. | High |
| US-005 | As a visitor, I want to learn about the founder, so that I feel confident in choosing the salon. | Medium |
| US-006 | As a customer, I want to request an appointment online, so that I can conveniently contact the salon. | High |
| US-007 | As a customer, I want to select multiple services while requesting an appointment, so that I can book everything I need in one request. | High |
| US-008 | As a customer, I want to provide additional notes with my appointment request, so that I can communicate any special requirements or skin sensitivities. | Medium |
| US-009 | As a visitor, I want to easily access the salon's contact information, so that I can reach out if I have any questions. | High |
| US-010 | As a mobile user, I want the website to adapt to my device, so that I can browse comfortably on any screen size. | High |
| US-011 | As a visitor, I want the website to load quickly and provide smooth animations, so that my browsing experience feels modern and professional. | Medium |
| US-012 | As a visitor, I want the interface to remain visually consistent across all sections, so that the website feels trustworthy and premium. | Medium |
