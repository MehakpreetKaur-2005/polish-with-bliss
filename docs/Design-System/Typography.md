# Typography System

## 1. Introduction
### 1.1 Purpose
The purpose of the Typography System is to ensure a consistent, elegant, and readable typographic language across all Polish with Bliss digital touchpoints. It reinforces the brand's boutique luxury positioning while maintaining high accessibility standards.

### 1.2 Typography Philosophy
Our typography is built on the principle of "Contrast and Harmony." We pair the sophisticated, high-contrast serifs of Playfair Display with the clean, modern clarity of Inter. This combination evokes a sense of timeless elegance balanced with professional expertise.

---

## 2. Font Families
### 2.1 Display Font (Headings)
- **Family**: Playfair Display
- **Type**: Serif
- **Usage**: Used for main hero titles, section headings, and significant brand statements. It conveys luxury, fashion, and boutique charm.

### 2.2 Body Font
- **Family**: Inter (or system sans-serif)
- **Type**: Sans-Serif
- **Usage**: Used for all body copy, descriptions, pricing lists, and form labels. It ensures maximum legibility across different screen sizes.

### 2.3 Accent Font
- **Family**: Great Vibes (or similar brand cursive)
- **Type**: Script
- **Usage**: Reserved strictly for the "Polish with Bliss" wordmark and very selective decorative taglines (e.g., founder signature).

---

## 3. Typography Scale
### 3.1 Hero Heading
- **Size**: 4rem (64px)
- **Weight**: Bold
- **Case**: Uppercase
- **Line Height**: 1.2

### 3.2 Section Heading
- **Size**: 2.5rem (40px)
- **Weight**: Semi Bold
- **Case**: Uppercase
- **Line Height**: 1.3

### 3.3 Card Titles
- **Size**: 1.25rem (20px)
- **Weight**: Semi Bold
- **Line Height**: 1.4

### 3.4 Body Text
- **Size**: 1rem (16px)
- **Weight**: Regular
- **Line Height**: 1.6

### 3.5 Captions
- **Size**: 0.875rem (14px)
- **Weight**: Regular
- **Line Height**: 1.5
- **Usage**: Metadata, footer copyright, and small supporting text.

### 3.6 Buttons
- **Size**: 0.875rem (14px)
- **Weight**: Semi Bold
- **Letter Spacing**: 0.05em
- **Case**: Mixed or Sentence case

### 3.7 Navigation
- **Size**: 0.938rem (15px)
- **Weight**: Medium
- **Letter Spacing**: 0.02em

---

## 4. Font Weights
### 4.1 Light (300)
Used occasionally for large decorative subtitles to create a delicate, airy feel.

### 4.2 Regular (400)
The standard weight for all body text, ensuring a comfortable reading experience.

### 4.3 Medium (500)
Used for navigation links and UI elements that need a slightly stronger presence than body text.

### 4.4 Semi Bold (600)
The default weight for section headers and sub-headers to establish clear hierarchy.

### 4.5 Bold (700)
Reserved for primary Hero headings and high-impact Call-to-Action labels.

---

## 5. Line Heights
- **Tight (1.1 - 1.2)**: Used for large display headings to keep them cohesive.
- **Normal (1.4 - 1.5)**: Used for sub-headings and UI components.
- **Reading (1.6)**: Used for all multi-line body text to reduce eye strain and improve flow.

---

## 6. Letter Spacing
- **Headings**: -0.01em (tightened for better visual density).
- **Body**: 0em (standard).
- **Navigation/Labels**: 0.02em to 0.05em (increased for better scannability at smaller sizes).

---

## 7. Responsive Typography
### 7.1 Desktop (> 1024px)
Full scale as defined in Section 3.

### 7.2 Tablet (640px - 1024px)
- Hero Headings scale down to 3rem (48px).
- Section Headings scale down to 2rem (32px).

### 7.3 Mobile (< 640px)
- Hero Headings scale down to 2.25rem (36px).
- Section Headings scale down to 1.75rem (28px).
- Body text remains at 16px to ensure accessibility.

---

## 8. Usage Guidelines
### 8.1 Heading Hierarchy
Always use headings in a logical sequence (H1 -> H2 -> H3). Never skip levels for styling purposes. H1 is reserved for the Hero section.

### 8.2 Text Alignment
- **Centered**: Default for boutique-style section headings and hero content to maintain a formal feel.
- **Left-Aligned**: Default for long-form body text (e.g., the Founder's message) to ensure optimal reading speed.

### 8.3 Readability Rules
- Max line length for body text: 65-75 characters (approx. 600px width).
- Avoid all-caps for body text or sentences longer than 3 words.
- Maintain a minimum contrast ratio of 4.5:1 against backgrounds.
